Para probar el mundo acuático se debe lanzar el siguiente comando: 

Bash

 ros2 launch controlador_submarino controller.launch.py

Si se desea cambiar de controlador, entre a la carpeta de controlador_submarino para ver cuáles son los que se puede probar.

Una vez decida que controlador y que alto nivel se quiere implementar, entre a la carpeta launch y siga los pasos establecidos. 

Recuerde hacer un catkin_make cada vez que modifique algo.
